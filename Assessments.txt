2. Deprecated keywords in JavaScript:

    -> Deprecated keywords are keywords or features that were used in
       older versions of JavaScript but are no longer recommended.

    Examples:

    1. var -> Older way of declaring variables. let and const are preferred.
    2. with -> Deprecated and not recommended in modern JavaScript.
    3. escape() -> Used to encode strings, but deprecated.
    4. unescape() -> Used to decode strings, but deprecated.
    5. arguments.caller -> Deprecated property.
    6. arguments.callee -> Deprecated property.
