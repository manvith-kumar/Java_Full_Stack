List: Used to display items in an organised way

Types:

1. Ordered list <ol> :
    Attributes:
    1. start -> numbers
    2. type -> i, I, 1, a, A
    3. reversed

    <li> tag is used to add elements

    Shortcut:


2. Unordered list <ul>:
    <ul></ul>

    Attributes:
    type -> circle, square, none, disc


3. Description/Definition list:
    <dl></dl> - represents definition list
    <dt></dt> - represents definition term
    <dd></dd> - represents definition description


4. Nested list:
    List inside another list
