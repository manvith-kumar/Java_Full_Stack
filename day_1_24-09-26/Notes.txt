Web Application :
-----------------
    Any application that will be run on browsers is called as a web application.

Types :
-------
    1. Static Web Applications
    --------------------------
        -> Any web applications doesn't have functionalities
        -> To build static web applications we will use only HTML and CSS

    2. Dynamic Web Applications
    ---------------------------
        -> Any web applications having functionalities is called dynamic web applications
        -> To build dynamic web applications HTML, CSS & JS required

TAGS :
------
    -> Tags are the predefined words which are enclosed with both opening and closing angular brackets

    Ex:
        <h1>, <p>, <div>

TYPES OF TAGS :
---------------
    1. Paired tags :
    ----------------
        -> Any tags having both opening and closing tags is called as a paired tag

        Ex:
            1. All heading tags
                <h1>heading tags-1</h1>
                <h2>heading tags-2</h2>
                <h3>heading tags-3</h3>
                <h4>heading tags-4</h4>
                <h5>heading tags-5</h5>
                <h6>heading tags-6</h6>

            2. Formatting tags
                i. <b> </b>                 -> font bold
                ii. <strong> </strong>     -> font bold
                iii. <i> </i>              -> font italic
                iv. <em> </em>             -> font italic
                v. <mark> </mark>          -> highlight the content
                vi. <u> </u>               -> underline
                vii. <sub> </sub>          -> subscript
                viii. <sup> </sup>         -> superscript
                ix. <marquee> </marquee>   -> to scroll the content <behavior = scroll/slide/alternate>
                x. <center> </center>      -> align content to center (only word for block level elements)
                xi. <strike> </strike>     -> to strike through the text (kotteyadam) <!--strike-->

            3. Other tags
                -> Ex: <p>, <div>, <span>, all list tags, media tags, semantic tags
