Types of Tags continuation of Day 1:
-----------------------------------
2. Unpaired Tags / Self Closing Tags:
------------------------------------
    -> Any tags having only opening tags are called Unpaired tags
    Ex: <br> , <img> , <hr> , <col> , <input> , <meta> etc

    i. Img tag:
    -----------
        -> <img> tag is one of the media tag used to display images on the web page

        -> Image attributes:
        ------------------
            1. src(source):
                    -> Absolute path(Browser images)
                    -> Relative path(Downloaded images)
            2. alt
            3. height
            4. width
            5. style
            6. id
            7. class

    Attributes:
    ----------
    -> Attributes are the additional information given to the tag
    -> Attributes are always in static(opening) tags
    -> Attributes are always in key and value
    Ex: <img src="image.jpg" alt="Sample Image">
